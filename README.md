# 四级备考网站（CET-4 60 天计划）

一个纯静态网站：打开就能用，自动按天生成大学英语四级备考任务，电脑和手机都能用，进度自动保存并支持跨设备同步。

## 1. 怎么打开

**方式一（推荐，功能最全）**

双击文件夹里的 `start-site.bat`，浏览器会自动打开 `http://127.0.0.1:8765/`，关闭那个黑色窗口即停止服务。

**方式二（更简单，部分功能受限）**

直接双击 `index.html`。功能和方式一相同，但“添加到手机主屏幕”“离线缓存”需要 http 地址才生效。

**方式三（手机上用）**

1. 先把整个文件夹放到电脑上能访问的位置，用 `start-site.bat` 启动。
2. 手机与电脑连同一个 Wi-Fi，在手机浏览器里打开 `http://电脑的局域网IP:8765/`（例如 `http://192.168.1.8:8765/`，用 `ipconfig` 查 IPv4 地址）。
3. 手机浏览器菜单里选择“添加到主屏幕”，之后就像 App 一样使用。
4. 想在公网随时访问，把整个文件夹上传到 GitHub Pages / Vercel / 腾讯云静态托管等任意静态托管服务即可，无需后端。

## 2. 网站包含什么

对照四级试卷的四个部分，全部题型都有对应的学习和练习内容：

| 部分 | 分值 | 网站提供的内容 |
| --- | --- | --- |
| 写作 | 106.5 | 16 个话题（议论文/图表/书信/通知），含三段提纲、必备表达、参考范文、评分标准、30 分钟计时与自评表 |
| 听力 | 248.5 | 12 组材料（短篇新闻 4 + 长对话 4 + 听力篇章 4），含题目解析、逐句精听、听写准确率对照、生词表 |
| 阅读 | 248.5 | 8 组材料（仔细阅读 / 长篇匹配 / 选词填空），含限时计时、逐题解析与定位句思路、生词表 |
| 翻译 | 106.5 | 16 个中国文化与生活话题段落，含参考译文、关键词与难点解析、20 分钟计时 |
| 词汇语法 | — | 377 个四级核心词（词性、释义、例句、发音）、48 个高频短语、20 组写作同义替换、18 个语法点、21 篇题型技巧 |

另外还有：60 天日历计划、模考中心（试卷结构 + 计时器 + 710 分制总分估算 + 成绩趋势）、学习统计（14 天学习时长、各阶段进度、模块分布）、错题与笔记。

## 3. 每天怎么用

1. 打开后默认进入「今日任务」，当天的词汇、听力、阅读、写作、翻译、语法、复盘任务已经排好，直接按顺序做。
2. 点「开始」进入任务详情：听力可逐句精听和听写，阅读和听力做完立即看解析，写作和翻译有计时器与参考范文/译文。
3. 每完成一项勾选一次，进度自动保存，首页环形进度和连续打卡会更新。
4. 每天结束前写一句复盘（错题属于哪一类、下次怎么做），比多做题更重要。

计划的节奏：**基础期（前 25%）→ 强化期（25%-55%）→ 提升期（55%-85%）→ 冲刺期（最后 15%）**，每周固定覆盖词汇、听力、阅读、写作、翻译、语法和一次模考；周日复盘并安排下周重点。词汇按遗忘曲线自动安排第 1/2/4/7/15 天的复习。

## 4. 进度同步（电脑 ⇄ 手机）

数据默认存在浏览器的 localStorage 里，同一个浏览器关掉再打开不会丢。跨设备有三种方式，在「设置与同步」页面：

1. **同步码（推荐）**：A 设备点「生成同步码」→「复制」；B 设备粘贴到输入框 →「合并导入」。不经过任何服务器，一台电脑换手机、换浏览器都能用。也可以点「复制为链接」，把链接发到手机直接打开导入。
2. **导出 / 导入文件**：导出 JSON 备份，通过微信或网盘传到手机后导入。
3. **云同步（自动）**：填写一个能读写 JSON 的地址即可自动同步，例如免费的 [npoint.io](https://www.npoint.io/) 端点（创建后把 bin ID 填到「npoint 标识」），或你自己的服务器接口。开启「自动同步」后，每次勾选任务会在 5 秒内上传。

> 说明：不配置第 3 种方式时，网站完全离线运行，不会向任何服务器发送数据。

## 5. 常见调整

- **考试日期不对**：设置页把「考试日期」改成你的实际考试日期（例如 12 月的考试填 `2026-12-19`），整站计划和倒计时会自动重新生成，已完成的进度按天数保留。
- **每天时间不够**：把「每日学习时长」改成 45 分钟或 1 小时，系统会自动精简任务，只保留词汇 + 当天主任务 + 复盘。
- **想加自己的单词**：设置页「自定义词库」按每行 `单词 中文释义` 粘贴，保存后自动排进每日任务。
- **听力没有声音**：网页用系统语音朗读（Windows 上是 Microsoft David/Zira 等），在设置里可以换语音、调语速；如果浏览器不支持朗读，听力材料仍可阅读原文与做题。

## 6. 目录结构

```
index.html                 页面外壳（导航、顶栏、脚本加载）
manifest.webmanifest       PWA 配置，支持“添加到主屏幕”
sw.js                      离线缓存
assets/css/app.css         全部样式（桌面侧边栏 + 手机底部导航）
assets/js/data-vocab.js    词库：377 词 + 48 短语 + 20 组同义替换
assets/js/data-reading.js  听力 12 组 + 阅读 8 组（含题目与解析）
assets/js/data-writing.js  写作 16 题（含范文）+ 翻译 16 题（含参考译文）
assets/js/data-skills.js   语法 18 点 + 技巧 21 篇 + 试卷结构与评分标准
assets/js/util.js          日期、DOM、语音朗读、计时器、导出等工具
assets/js/libs.js          题库解析与检索
assets/js/store.js         进度存储、同步码、云同步
assets/js/plan.js          备考计划引擎（阶段、周节奏、遗忘曲线、任务时长）
assets/js/practice.js      词汇 / 听力 / 阅读练习
assets/js/practice2.js     写作 / 翻译 / 语法 / 技巧 / 复盘 / 模考中心
assets/js/views.js         路由与各页面
tools/selftest.mjs         自检脚本：node tools/selftest.mjs
tools/make-icons.mjs       生成 PWA 图标 PNG
start-site.bat             一键启动本地服务器
```

## 7. 自检

```
node tools/selftest.mjs
```

会检查题库完整性、计划生成、每天任务时长、245 个任务详情渲染、各页面渲染、同步码往返、导入导出等 17 项内容。
